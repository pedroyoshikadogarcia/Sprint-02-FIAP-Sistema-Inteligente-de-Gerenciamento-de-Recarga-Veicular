# Sprint-02-FIAP-Sistema-Inteligente-de-Gerenciamento-de-Recarga-Veicular
Sistema Inteligente de Gerenciamento de Recarga para VEs em C. Desenvolvido para a Sprint 2 (FIAP 2026), inclui controle de múltiplas sessões, Smart Charging com Peak Shaving, tarifação dinâmica por horário de pico e simulação de telemetria baseada no mapa Modbus real do carregador GoodWe HCA G2.
